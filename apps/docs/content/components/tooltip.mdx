## Accessibility

- `role="tooltip"`, linked to the trigger with `aria-describedby`, so it is read as the description.
- Dismissable with Esc, hoverable and persistent (WCAG 1.4.13).
- In the top layer with `popover="manual"`, so nothing can clip it.
- Esc inside a dialog hides the tooltip only; the next Esc closes the dialog.
