## Accessibility

- `KerbProvider` renders two hidden regions once: polite and assertive. They exist from the first render, so screen readers know them.
- A repeated message is announced again; the same text within a second is dropped.
- Regions are emptied after 7 seconds, so stale text is not found later.
- Kerb’s own components announce through it: toasts, the date picker’s month, Preferences.
