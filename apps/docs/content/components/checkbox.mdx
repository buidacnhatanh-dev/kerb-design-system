## Accessibility

- A native `<input type="checkbox">` over a styled box; the whole row is the label, at least 44 pixels high.
- The mixed state is set on the input, so it is read as “mixed”.
- The hint is outside the label and linked as the description.
- An error for a required checkbox has an icon and text, not colour alone.
