## Accessibility

- One native text field in the locale’s format, so typing and pasting always work. The hint shows the format.
- The calendar is a non modal dialog with a `role="grid"` built on React Aria’s calendar hooks.
- The week starts on the locale’s first day: Monday in German.
- Month changes are announced through the shared Announcer.
- Errors appear on blur or Enter, never while typing.
